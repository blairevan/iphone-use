# 安全远程访问与凭据管理

新安装仅监听本机回环地址。更改 `IPHONE_USE_HOST` 为 `0.0.0.0` 不会授权明文远程访问；
非回环 HTTP 请求被拒绝。安装器不会主动创建公网域名、修改防火墙或安装信任根。

## 开启前的条件

准备一个证书链与域名能通过系统验证的 HTTPS 入口，以及不同的非空
`IPHONE_USE_PASSWORD` 和 `IPHONE_USE_AGENT_TOKEN`。将凭据保存于当前实例受保护的
LaunchAgent 配置，不要放进 URL、shell 历史、截图或日志。现有密码不应为升级而轮换。

TLS 可终止于操作者选择的本机反向代理，也可使用现有 HTTPS/WSS 中继。反向代理到
daemon 的 HTTP 跳必须走本机回环，必须保留外部 Host，覆盖 `X-Forwarded-Proto: https`
和单值 `X-Real-IP`，而不是追加或透传客户端的转发头。互联网不能绕过代理访问后端端口。
证书签发、续期、域名及访问策略由所选择的 TLS 服务负责；本程序不提供“忽略证书错误”选项。

**中继是被信任的 TLS 终止方，不是端到端加密保证。** 它能接触经转发的请求与画面，必须
同样保护其部署权限、日志和凭据。WSS 只保护 daemon 到中继这一跳，不会消除对中继的信任。

## 显式开启、检查及关闭

以下命令用于已有正常安装的实例；先检查自己的 HTTPS 地址，不要原样使用示例域名。

```sh
iphone-use remote status
iphone-use remote enable --url https://control.example/phone-one --confirm
# 已配置中继时，显式指定其 HTTPS 基地址及该设备的公开路径。
iphone-use remote enable --url https://relay.example/p/DEVICE_ID --relay https://relay.example --confirm
# 命名实例使用自己的状态目录、凭据和端口。
iphone-use remote status --instance phone-two
iphone-use remote disable --instance phone-two --confirm
```

开启操作写入实例私有 `remote.json`，保持 daemon 在回环地址，设置公开路径并重新启动该
实例。只有 TLS 检查及设备身份探测同时通过才保留新配置；失败恢复旧配置并尝试恢复服务。
无法恢复服务时明确报错，不报告成功。身份探测签名绑定 nonce **和完整的公开 HTTPS 基地址**，
第三方不能通过转发一个旧式 nonce-only 回答来成为新的可信连接地址。

关闭操作清除远程 profile 的公开入口，覆盖遗留环境变量中的中继配置，并撤销旧设备授权。
重新开启后，被撤销的设备需要重新配对。本机服务保持可用。外部反向代理本身的生命周期由
它的操作者管理；daemon 不把保留着的代理配置当成继续远程开放的授权。

局域网与外网可使用同一个 HTTPS 域名的分区 DNS；证书仍必须匹配同一个域名。不能自动切回
HTTP 私网 IP。没有经过配置和验证的第二个 HTTPS 地址，也不会仅凭“同一局域网”获得凭据。

## 已配对 iOS App 的迁移

先部署支持安全迁移的 daemon，再编辑 App 中保存的地址。App 先验证 TLS 及绑定目的地址的
设备身份证明，之后才续期会话并读取状态。新连接未验证成功时保留原地址及 Keychain 内容；
所有凭据复制成功后才删除旧项。没有身份证明密钥的旧档案需在新 HTTPS 地址重新扫码配对。

已有显式保存的 HTTP 连接仅用于迁移兼容，不代表可用于安全远程访问。已配对 HTTPS 不会
自动降级，重定向也不会把凭据带到其他协议、主机或端口。设备凭据撤销后不会再用保存的
密码悄悄重新登录；必须重新授权。

## 管理与撤销

在已登录的同源浏览器打开 `/security`（有实例路径时使用 `<base>/security`）。
查看、创建或撤销凭据均要求重新输入管理员密码。新 agent 凭据仅在创建响应中展示一次，
可授予 `read` 或 `control`。旧的共享 bearer 明确属于共享身份，不能冒充多个独立 agent。

每个设备和浏览器会话具有独立记录。撤销会在认证层生效并持久化，拒绝新请求及 token 续期，
关闭已建立的受保护响应流，并取消该主体拥有的任务；不会仅隐藏管理界面条目。
任务确认必须携带实际展示提示中的 `confirmation_id`，旧确认不能批准新步骤。管理员接管
另需新鲜密码与原因，接管本身不批准待执行动作。详见 [任务 API](../agent-task.md)。

安全事件保留操作类型和不透明主体标识；默认运行日志不记录密码、token、输入、屏幕文字或
完整错误体。请求计时和运行统计的持久日志也不保存原始 owner/run 名称或任意 URL 参数。

## 验证边界

本仓库提供真实回环 HTTP/TLS 协议测试、Swift 迁移夹具和中继协议测试。它们不替代实际
域名证书、生产中继、手机扫码及真实移动网络切换验收。不得把临时测试 CA 导入系统或用于生产，
也不得把未连接手机的 daemon 健康状态描述成“已能控制真机”。具体结果见
[实施与验收记录](hardening-status.md)。
